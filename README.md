# Не по стипендии

Интернет-магазин вещей, на которые студент ИТМО пока может только посмотреть (дышать рядом нельзя). Цены показаны в рублях и в стипендиях!

**Демо:** https://meranthh.github.io/webprog_shop/
## Возможности

- каталог товаров с карточками и модальным окном «Подробнее»;
- корзина в выезжающей панели: добавление, удаление, изменение количества;
- автоматический пересчёт итоговой суммы (в рублях и стипендиях);
- сохранение корзины в `localStorage` после перезагрузки страницы;
- форма оформления заказа с проверкой полей и сообщением «Заказ создан!»;
- адаптивная вёрстка для ноутбука, планшета и телефона.

## Технологии

HTML, CSS (flexbox, grid, медиазапросы), JavaScript без фреймворков.

## Структура

```
index.html
favicon.svg
css/style.css
js/data.js     — данные о товарах
js/main.js     — логика каталога, корзины и формы
img/           — изображения 
```

## Запуск

Откройте командой ` open index.html` в терминале или перейдите по ссылке на демо!
